# Gym Bro — контекст для Claude Code

Полная память проекта — в [README.md](README.md): структура, источники данных,
журнал изменений, что не сделано. Читай его первым, здесь только правила работы.

## Стек
- Сайт: Next.js 16 + TypeScript + Tailwind v4, деплой GitHub Pages (статический экспорт)
- Приложение: Expo (React Native) + TypeScript
- Бэкенд: Supabase (auth + база + storage) — ещё не подключён

## Конвенции
- Весь код на TypeScript
- Модель данных менять только через `shared/types.ts`, синхронно для web и mobile.
  В web импорт через `@shared/types`
- Стили только Tailwind (web) / StyleSheet (mobile), без inline-стилей
- Дизайн строго по `design-system.md`: тёмно-синий фон, ОДИН стальной акцент,
  тонкий сериф в заголовках, кнопки-пилюли. Второй акцентный цвет не вводить,
  статусы различать текстом, а не цветом
- Сайт — витрина-приложение, а не лендинг. Маркетинговых пояснений вида
  «почему мы выбрали эту фичу» на сайте быть не должно

## Данные упражнений — не выдумывать
У каждого упражнения в `web/src/lib/demo.ts` есть поле `evidence`:
`emg` (процент из исследования), `ranking` (порядок без процентов) или
`estimate` (исследования нет). Добавляя упражнение, обязательно проставь
источник. Ссылки на исследования — в README, в интерфейсе только подпись.

Не терять оговорку: ЭМГ измеряет активацию в моменте и не предсказывает рост
мышцы. Объём и прогрессия важнее выбора упражнения.

## Фигура человека
`BodyTab.tsx` рисует половину фигуры (`x < 160`, viewBox `0 0 320 720`) и зеркалит
её. Правь только левую половину — правая получится сама.

## Фичи приложения (MVP)
1. **Анализ тела и рекомендации по упражнениям** — классификация по
   эффективности, сложности выполнения и прорабатываемым мышцам.
2. **Схема человека на базе фото** — развитие мышцы по росту, весу, возрасту;
   заполненность показывает набранный объём, чтобы не было перетрена.
3. **Программы тренировок** с авто-отсчётом отдыха, заменой упражнения на ту же
   группу и произвольным временем тренировки.
4. **ИИ-помощник (вкладка GymBro, платная)** — генерирует программы, меняет их
   при боли, подбирает веса, оценивает реалистичность личной цели.
5. **Челленджи** — выполнимые недельные задачи, в том числе вдвоём с другом.
