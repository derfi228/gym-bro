# Gym Bro — контекст для Claude Code

## Стек
- Сайт: Next.js + TypeScript + Tailwind, деплой GitHub Pages (статический экспорт)
- Приложение: Expo (React Native) + TypeScript
- Бэкенд: Supabase (auth + база + storage)

## Структура
- web/ — сайт (Next.js, App Router, src/, Tailwind v4, ESLint)
- mobile/ — мобильное приложение (Expo, TypeScript)
- shared/ — общие типы и контракты данных между сайтом и приложением

## Конвенции
- Весь код на TypeScript
- Стили только через Tailwind (web) / StyleSheet (mobile), без inline-стилей
- Модель данных менять только через shared/types.ts, синхронно для web и mobile
- В web общие типы импортируются как `@shared/types` (алиас в web/tsconfig.json)
- Дизайн сайта — по design-system.md: тёмно-синий фон, один стальной акцент,
  тонкий сериф Cormorant в заголовках, кнопки-пилюли. Второй акцентный цвет не вводить.

## Продукт
Основа — мобильное приложение, сайт остаётся витриной.
Ключевое отличие от конкурентов: они перегружены, мы делаем ровно пять функций.

## Фичи приложения (MVP)
1. **Анализ тела и рекомендации по упражнениям** — классификация упражнений по
   эффективности, сложности выполнения и прорабатываемым мышцам. Показывает самые
   эффективные упражнения для развития той или иной мышцы.
2. **Схема человека на базе фото тела пользователя** — отражает развитие мышцы по
   параметрам роста, веса и возраста. На схеме показана заполненность (сколько
   сделано нужного объёма на ту или иную мышцу), чтобы не было перетрена, после
   того как записано выполненное упражнение.
3. **Предлагаемые программы тренировок** с авто-измерением отдыха и возможностью
   редактирования под себя: замена упражнения на другое на ту же группу мышц
   (список от самого рекомендованного до самого неподходящего), указание
   конкретного времени тренировки — например, программа под 35 минут.
4. **ИИ-помощник (вкладка GymBro, платная фича)** — генерирует индивидуальные
   программы: меняет программу, если что-то болит, подбирает веса под конкретный
   подход, даёт рекомендации по упражнениям. Можно задать персональную цель
   (пожать 100 кг до конца лета, сбросить 5 кг). Если цель реальна — подгоняет
   программу под неё, если нет — так и пишет.
5. **Челленджи** — каждую неделю предлагаются реальные для выполнения челленджи
   (например, сходить в зал 3 раза), в том числе для совместного прохождения с
   другом (огонёк как в TikTok).
