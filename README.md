# Gym Bro

Приложение для тренировок в зале: карта мышц по недельному объёму, каталог
упражнений на данных ЭМГ-исследований, конструктор программ и помощник,
работающий с состоянием приложения.

Монорепозиторий: сайт на Next.js, мобильное приложение на Expo, общая модель
данных.

**Демо:** https://derfi228.github.io/gym-bro/

## Возможности

**Карта мышц**
- 13 групп, проекции спереди и сзади, переключение кнопкой
- Анатомические контуры, левая и правая стороны отрисованы раздельно
- Каждая группа обведена контуром, выбранная выделяется ярче и толще
- Заливка поднимается снизу вверх и показывает набранный объём относительно
  рабочего диапазона, высота меняется анимацией
- Цвет заливки — статус группы: не затронута, мало, в диапазоне, много, перебор
- Перебор объёма дополнительно отмечается пунктирным контуром
- Наведение показывает подходы и статус, клик открывает упражнения группы

**Каталог упражнений**
- 62 упражнения, фильтр по группам, сортировка по активации или сложности
- Карточка упражнения: техника выполнения, разбор вовлечённых мышц с процентами
- Вовлечённые мышцы подсвечиваются на карте, яркость соответствует вкладу
- Поля пикового и рабочего веса с шагом 1 кг, расчёт рабочего в процентах от пикового

**Программы**
- Конструктор под произвольную длительность от 10 до 120 минут
- Отстающие группы ставятся первыми, перебранные пропускаются
- Схема тела рядом со списком: пересчитывается на каждое изменение, переключается
  между «только тренировка» и «неделя целиком»
- Подходы меняются шагом в строке упражнения, упражнения переставляются и убираются
- Добавление нового упражнения от группы, с недельным диапазоном перед списком
- Блок «Что поправить»: пропущенные и перегруженные группы, правка одной кнопкой
- Замена упражнения на альтернативу для той же группы
- Таймер отдыха с обратным отсчётом
- Справочник методик: фулбоди, верх/низ, PPL, GVT, сплит по группам, Max-OT —
  с оценкой соответствия данным о частоте и объёме
- У методики раскрываются тренировочные дни со списком упражнений, каждое
  открывается в своей карточке

**GymBro**
- Читает недельный объём: отвечает, что отстаёт и где перебор
- Собирает программу под запрос и открывает её во вкладке «Программа»
- Исключает группу из подбора при травме

**Челленджи**
- Недельные задачи с прогрессом, совместные с другом, счётчик серии

**Связь между разделами**
Подход засчитывается целевой мышце полностью, ощутимо вовлечённой —
наполовину; так считается и записанная тренировка, и объём собираемой
программы. Карта мышц обновляется сразу.

## Запуск

Требуется Node.js 22+.

```bash
git clone https://github.com/derfi228/gym-bro.git
```

Сайт на http://localhost:3000:

```bash
cd web && npm install && npm run dev
```

Мобильное приложение:

```bash
cd mobile && npm install && npx expo start
```

## Разработка

- Модель данных живёт в `shared/types.ts`, в web импортируется как
  `@shared/types` (алиас в `web/tsconfig.json`)
- Стили: Tailwind в web, StyleSheet в mobile
- Палитра и компоненты описаны в `design-system.md`: тёмно-синий фон, один
  акцентный цвет, сериф Cormorant в заголовках, кнопки-пилюли
- Контуры тела лежат в `web/src/lib/bodyPaths.ts` — файл сгенерирован из
  react-native-body-highlighter, правится только перегенерацией
- Шесть групп в нём слиты из отдельных брюшек в цельные мышцы и переведены в
  кривые: предплечья и квадрицепс спереди, предплечья, трицепс, спина, бицепс
  бедра и икры сзади. Икры и трицепс спереди оставлены исходными

### Формат данных упражнения

```ts
{
  id, name, primary, secondary,
  involvement: { quads: 1, glutes: 0.8 },   // вклад группы 0..1, для подсветки
  description,                               // техника выполнения
  emgPercent: 100 | null,                    // % активации из исследования
  rank: 1,                                   // место в рейтинге, если процентов нет
  evidence: "emg" | "ranking" | "estimate",
  sourceId, difficulty, equipment, note
}
```

`evidence` обязателен при добавлении упражнения:

- `emg` — процент активации целевой мышцы относительно лучшего упражнения того
  же исследования
- `ranking` — исследование опубликовало порядок без процентов
- `estimate` — сравнительного исследования нет, значение экспертное

Ограничение метода: ЭМГ измеряет активацию мышцы в моменте и не является
подтверждённым предиктором гипертрофии —
[Vigotsky и др., Sports Medicine 2022](https://link.springer.com/article/10.1007/s40279-021-01619-2).
Значения в каталоге сравнивают упражнения между собой, а не прогнозируют рост.

### Недельный объём по группам

Границы MEV / MAV / MRV лежат в `web/src/lib/landmarks.ts` — одна таблица на
13 групп, от неё считаются заливка тела, статусы и правки к программе.

| Ориентир | Что означает |
|---|---|
| MEV | минимум, ниже которого прироста практически нет |
| MAV | рабочий диапазон |
| MRV | потолок, выше которого восстановление не успевает |

- Нижняя граница: [Schoenfeld, Ogborn, Krieger, 2017](https://pubmed.ncbi.nlm.nih.gov/27433992/) —
  дозозависимая связь объёма и гипертрофии, рост до ~10 подходов в неделю
- Подтверждение: [Baz-Valle и др., 2022](https://pubmed.ncbi.nlm.nih.gov/35291645/) —
  систематический обзор объёма
- Сами значения landmarks — Israetel и др., «Scientific Principles of
  Hypertrophy Training». Это модель планирования, а не мета-анализ: у групп с
  `basis: "model"` цифра держится только на ней
- Деление недельного диапазона пополам на одну тренировку — из данных о частоте:
  [Schoenfeld и др., 2016](https://link.springer.com/article/10.1007/s40279-016-0543-8)

Ограничение: индивидуальная переносимость объёма различается в разы, поэтому в
интерфейсе это «диапазон», а не «норма».

## Деплой

Пуш в `main` с изменениями в `web/`, `shared/` или workflow запускает сборку
статики и публикацию на GitHub Pages. Базовый путь задаётся переменной
`NEXT_PUBLIC_BASE_PATH=/gym-bro`; локально она не нужна.

```bash
gh run list --limit 3
```

Если сборка висит в очереди и не стартует, её держит предыдущий запуск через
`concurrency: pages`. Запустить заново:

```bash
gh workflow run deploy.yml --ref main
```
